# Word 导入大小提示与自动图片压缩方案

> 版本：v1.0
>
> 状态：已实施（2026-10-18）
>
> 说明：本方案已同步落实到项目列表与项目实施页的 Word 导入入口。

## Summary

- 页面明确显示 Word 导入大小规则。
- 55 MiB 以内直接导入；55–150 MiB 由系统自动压缩图片；超过 150 MiB 禁止导入并显示手工压缩教程。
- 自动压缩只处理 DOCX 内嵌图片，不修改文字、表格、样式和项目数据。
- 压缩成功后只保存压缩版，用户电脑上的原始 Word 不受影响。

## Implementation Changes

### 页面与导入流程

- 项目列表和项目实施页统一显示：
  - 不超过 55 MiB：直接导入。
  - 大于 55 MiB 且不超过 150 MiB：需确认后自动优化图片。
  - 超过 150 MiB：不读取，提示使用 Word 或 WPS 手工压缩。
- 超过 55 MiB 时显示原文件大小、压缩说明和清晰度策略；压缩完成后显示压缩前后大小。
- 压缩或校验失败时停止导入，不覆盖当前项目数据，并展示 Word/WPS 压缩步骤。
- 两个 Word 导入入口共用相同的大小判断和错误提示。

### 自动压缩

- 新增二进制 DOCX 优化接口，最大接收 150 MiB，避免现有 Base64 带来的约 60 MiB 限制。
- 使用 DOCX ZIP 结构读取 `word/media`：
  - 第一轮：最长边 2400 像素，JPEG 质量 88，PNG 保持透明通道并采用最高压缩。
  - 若仍超过 55 MiB：第二轮降到最长边 1800 像素、JPEG 质量 82。
  - 图片小于目标尺寸时不放大；优化结果比原图更大时保留原图。
  - GIF、EMF、WMF 及其他不支持格式保持原样。
- 重新生成 DOCX 后校验 ZIP、`word/document.xml` 和媒体文件完整性；最终仍超过 55 MiB 则不继续导入。
- 优化接口只返回临时压缩结果，不直接修改项目；页面解析及项目保存成功后，才将压缩版保存为项目报告模板。

### 接口与兼容性

- 新增 DOCX 二进制优化接口，返回压缩后的 DOCX，并通过响应头返回原始大小、压缩后大小及优化图片数量。
- 保留现有报告模板上传接口和 80 MB JSON 限制，其他上传功能不受影响。
- 为请求过大、无效 DOCX、图片处理失败和压缩后仍超限分别返回明确错误信息。
- 源码页面与安装版运行页面同步更新。

## Test Plan

- 10 MiB、55 MiB 以内 DOCX 不压缩，正常解析和保存。
- 55–150 MiB、包含 JPEG/PNG 的 DOCX 压缩到 55 MiB 以内并成功导入。
- 第一轮无法达标时验证第二轮压缩；仍无法达标时不覆盖项目。
- 超过 150 MiB 时前端立即拦截并显示手工压缩教程。
- 验证透明 PNG、旋转照片、截图小字、GIF 及 EMF/WMF。
- 验证压缩后的 DOCX 可由 Word/WPS 正常打开，文字、表格、样式、图片顺序及关联关系不变。
- 验证项目列表和实施页面两个入口行为一致。
- 验证损坏 DOCX、非 DOCX 改扩展名、网络中断及后端处理失败。
- 回归现有 Word 导入、阶段数据保存、证据图片提取和报告模板保存。

## Assumptions

- 55 MiB 为自动压缩触发及压缩后安全上限，150 MiB 为原始文件硬上限。
- 自动压缩采用“报告清晰优先”策略。
- 系统只保存压缩版，不额外保存原始 Word。
- 用户本地原始文件不会被修改；自动压缩失败时由用户按页面教程手工处理。

## 手工压缩参考

### Microsoft Word

1. 打开报告并先另存为副本。
2. 点击任意图片，进入“图片格式”→“压缩图片”。
3. 取消“仅应用于此图片”，勾选“删除图片的裁剪区域”。
4. 优先选择“打印（220 ppi）”；仍超过限制时再选择“网页（150 ppi）”。
5. 保存并关闭 Word，确认文件大小后重新导入。

### WPS

1. 点击任意图片，进入“图片工具”→“压缩图片”。
2. 选择应用到文档中的所有图片。
3. 优先选择 220 ppi；文件仍过大时再降低到 150 ppi。
4. 不建议直接使用 96 ppi，以免证据截图中的小字模糊。

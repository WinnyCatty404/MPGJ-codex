# 密评报告工具修改记录

本文件简要记录阶段性功能变化。详细差异以 Git 提交历史为准。

## 2026-10-12

- 完善现场证据管理：支持从剪贴板粘贴图片、证据分组与引用、图片独立存储、旧数据迁移，以及复测项目复制证据。
- 优化报告生成：同组现场证据图片优先同排展示，规范风险分析表叙述文本格式，并更新二级、三级报告模板。
- 改进报告编辑体验：增加结果记录全文编辑、证据抽屉、报告分析分段阅读与编辑、总体评价和改进建议分层展示，并保护自动计算的综合得分与结论。
- 完善项目操作：项目列表在重新获得焦点时刷新，复制项目时增加处理中状态，规划文本框支持随内容自适应高度。
- 补充报告内容一致性审核规则 v1.0，为后续审核功能开发提供规则依据。
- 增加 Linux 部署、启动、停止、备份、恢复和卸载脚本，并补充部署说明。
- 更新产品品牌图片、Windows 控制台任务栏标识和安装包配置。

## 2026-10-08

- 支持中文安装路径与独立数据目录，重构 Windows 无窗口安装包。
- 更新二级、三级报告模板，完善 Windows 安装和数据目录管理。
- 内置 10 个初始用户，并增加用户批量导入功能。

## 2026-10-05 及以前

- 完善项目 README、架构、部署、数据模型与安全说明。
- 完成二级、三级报告的基础生成、模板导出和项目核心流程。

# BMPBGS 密评协同管理系统用户使用手册

## 一、手册说明

本手册面向 BMPBGS 密评协同管理系统的日常使用者，覆盖从登录、项目管理、五阶段测评实施到报告导出的完整操作流程，兼顾用户管理、模板设置等管理功能。手册按"操作流程齐全、细节覆盖到位"的原则编写，阅读时无需技术背景，按步骤操作即可。

适用读者：测评人员、项目负责人、审核人员、系统管理员。

系统定位：覆盖商业密码应用安全性评估项目"项目准备、方案编制、现场测评、报告编制、报告导出"五个阶段的协同工作台，实现测评数据、风险与报告的同源管理。

配套文档：系统的安装、数据迁移、备份与恢复操作，请参见《BMPBGS 安装与数据迁移备份恢复指南》。

## 二、快速上手

### 2.1 启动与访问

1. 双击桌面"BMPBGS 控制台"快捷方式（或在开始菜单中找到同名程序）。
2. 在控制台界面点击"启动系统"，等待启动完成的提示（首次启动会自动初始化数据库，时间稍长）。
3. 点击"打开系统"，浏览器会自动打开系统登录页；也可以在浏览器中手动输入控制台显示的访问地址（默认 http://localhost:5173，端口以控制台实际显示为准）。
4. 使用完毕后，点击控制台的"停止系统"即可关闭服务。

### 2.2 登录与首次修改密码

1. 在登录页输入用户名和密码。系统初始管理员账号为 admin，初始密码为 Admin@123。
2. 点击"登录系统"。
3. 首次登录时系统会要求修改初始密码，按提示设置新密码（长度至少 8 位）后重新登录。修改成功后，账号状态由"待改密"变为"正常"。
4. 登录状态有效期为 8 小时，超时后需重新登录；重新登录前编辑但未保存的内容不会保留，请及时保存。

日常修改密码：点击页面右上角顶栏的"修改密码"，依次输入当前密码、新密码、确认新密码即可。

### 2.3 界面导览

系统采用"左侧导航 + 顶部工具栏"布局：

| 区域 | 内容 |
| --- | --- |
| 左侧导航 | 工作台、项目管理、用户管理；管理员额外显示测评机构、模板设置、风险分析 |
| 顶部工具栏 | 当前页面名称、修改密码、深色/浅色模式切换、通知、当前用户与角色、退出 |
| 内容区 | 各功能页面的主要内容 |

顶栏右侧的"深色模式/浅色模式"按钮可随时切换界面主题；点击"退出"安全注销并返回登录页。

## 三、角色与权限

系统内置四种角色，不同角色的分工如下：

| 角色 | 角色说明 | 典型工作 |
| --- | --- | --- |
| 系统管理员（admin） | 负责系统配置与账号管理 | 用户管理、模板设置、测评机构信息、风险模板库、数据备份恢复 |
| 项目负责人（manager） | 对项目全周期负责 | 创建项目、组织方案编制、审核测评记录、推进各阶段 |
| 测评人员（evaluator） | 测评实施的具体执行者 | 填写方案、现场记录、归集证据、编制报告初稿 |
| 审核人员（reviewer） | 报告质量复核 | 复核风险与结论、审核报告、归档意见 |

权限说明：

- "测评机构""模板设置""风险分析"三个页面仅对系统管理员开放，其他角色在左侧导航中不可见。
- "用户管理"页面所有角色可见，但添加用户、批量导入为管理员专属操作；重置密码、启用/禁用等管理动作请使用管理员账号执行。
- 项目及测评数据对所有角色开放编辑，请各单位按内部分工各司其职。

## 四、工作台

登录后默认进入工作台，是日常工作的总览入口：

- **欢迎区**：显示当天日期与问候语，右上角"＋ 新建项目"按钮可直接创建项目。
- **指标卡**：依次展示项目总数、实施中、审核中、已完成的项目数量。
- **最近项目**：按最后更新时间排序展示最近项目，包含项目名称、编号、责任单位、状态、进度与负责人；点击任意一行直接进入该项目工作区。点击"查看全部"跳转项目管理页。
- **流程分布**：以条形图展示当前项目所处的五个阶段分布，便于掌握整体进度。
- **高风险提示**：提醒"正式导出报告前，应确保高风险项已有明确处置意见和证据"。

## 五、项目管理

### 5.1 查看与筛选

点击左侧导航"项目管理"进入项目列表：

- **搜索框**：支持按项目编号、报告编号、系统名称、责任单位搜索，输入后按回车键执行。
- **筛选条件**：可按测评年度、系统等级（二级/三级/四级）、项目状态（草稿/实施中/审核中/已完成）组合筛选，点击"查询"按钮生效。
- **列表信息**：每行展示项目（名称、编号、报告编号、责任单位）、测评年度、系统等级、项目周期、当前阶段与状态、系统评分（满分 100）、进度条，以及操作按钮。

### 5.2 新建项目

1. 点击页面右上角"＋ 新建项目"。
2. 在弹出的对话框中填写：
   - **项目编号**：系统按"MP-测评年度-序号"自动生成，只读，不可修改。
   - **报告编号**：可稍后补充，也可在后续通过"导入 Word"自动带入。
   - **系统名称**、**责任单位**：必填，请填写全称。
   - **测评年度**：默认当前年份，可修改。
   - **系统等级**：可选择二级或三级。
3. 点击"创建并进入项目"，项目创建成功并出现在列表中。

### 5.3 编辑、复制与删除

- **编辑**：点击项目行的"编辑"按钮，可修改报告编号、系统名称、责任单位、测评年度、系统等级，保存后立即生效。
- **复制为复测项目**：点击"复制"按钮，填写新的系统名称、报告编号和测评年度后确认。复制将保留原项目的测评过程日期、现场测评记录、八个安全层面的证据列表及全部证据图片；附录 B 的独立材料将被清空。适用于同一系统的年度复测。
- **删除**：点击"删除"按钮并确认。删除将移除该项目及其阶段数据、资产、测评记录、风险和证据文件记录，**此操作不可恢复**，请谨慎使用。

### 5.4 进入项目工作区

点击项目行的"实施"按钮，系统在新标签页打开该项目的工作区，按五个阶段组织全部测评工作，操作方法详见第六章。

### 5.5 从 Word 报告导入

如果被测评单位此前的密评报告已有 Word 版本，可导入后自动填充方案与测评数据：

1. 在项目管理列表点击目标项目的"导入 Word"。
2. 选择密评报告 .docx 文件，等待上传完成，系统自动进入项目并解析报告。
3. 在导入选项界面确认需要导入的内容（可按需选择"图片层面与上方文字选择同步"）。
4. 点击"开始导入"，系统自动填充步骤 2/3/4 的相关内容，完成后提示导入结果。

导入内容为自动解析结果，请对照原报告逐项核对后再进入正式流程。

## 六、项目工作区：五阶段操作

工作区顶部为步骤条，依次为：1 项目准备、2 测评准备与方案编制、3 现场测评、4 报告编制、5 报告导出，点击步骤可自由切换。每个模块编辑后请及时点击对应的保存按钮；步骤 2 的部分模块提供"保存并进入下一项"按钮，可顺序推进。

### 6.1 阶段一 项目准备

本阶段录入被测单位与项目的基础信息，用于报告封面、项目档案及联系信息：

1. **被测单位基本信息**：填写单位名称（自动带出责任单位）、邮政编码、单位地址、密码管理部门、联系人、职务/职称、移动电话。
2. **项目基本信息**：核对系统名称、系统等级、开始日期、结束日期（取自项目档案）。
3. 点击"保存被测单位信息"保存；点击"重置"清空重填。

### 6.2 阶段二 测评准备与方案编制

本阶段通过左侧选项卡逐项编制测评方案，各选项卡相互独立，可随时切换、分别保存：

| 选项卡 | 填写内容 | 操作按钮 |
| --- | --- | --- |
| 简介 | 系统简介、测评情况简介、测评目的 | 保存简介内容、恢复默认模板 |
| 测评依据 | 法律法规和政策文件、标准规范（如 GB/T 39786—2021）、项目相关文件，每行一项 | 新增、删除、保存测评依据 |
| 被测系统情况 | 业务情况；网络结构与边界（支持图文块：添加文字、添加图片、调整顺序、删除）；密码应用情况 | 保存承载的业务情况、保存网络拓扑图及描述 |
| 密码应用 | 按层面录入密码应用概况、密码服务、密钥管理（对称/非对称密钥逐行登记，可添加、删除、撤销删除） | 上一层面、保存并进入下一层面 |
| 系统资产 | 按十类资产登记：物理环境、安全设备、密码产品、服务器、网络设备、数据库、应用系统（含应用用户）、数据、文档、人员；每类可增加、删除行 | 恢复默认、保存系统资产 |
| 测评过程 | 项目准备安排、现场测评安排、报告编制与审核安排（日期、内容、责任人） | 保存测评过程 |
| 测评对象 | 按五个安全层面添加测评对象；可点击"⇄ 同步系统资产"把资产中勾选测评的资产同步到对应层面 | 添加测评对象、保存测评对象 |
| 测评指标 | 逐项勾选指标是否适用，不适用须填写原因；工具栏可"全部适用/全部不适用"，并显示已完成计数 | 保存测评指标 |
| 测评方法及工具 | 测评方法、工具清单（名称、版本、用途）、工具接入点（支持粘贴或导入图片） | 添加工具、添加接入点、保存测评方法及工具 |
| 前次测评情况 | 测评次数、前次测评时间、测评机构、评估结论、综合得分、主要问题与整改情况 | 保存前次测评情况 |

### 6.3 阶段三 现场测评

本阶段按八个安全层面逐项记录测评结果、问题与证据：

1. 在左侧选择安全层面：物理和环境安全、网络和通信安全、设备和计算安全、应用和数据安全、管理制度、人员管理、建设运行、应急处置。
2. 在每个测评单元下，针对各测评对象逐项选择测评结果：**符合、部分符合、不符合、不适用**。
3. 填写问题描述；需要证据的位置插入证据编号。
4. **证据归集**：在现场记录框中按 Ctrl+V 粘贴截图，或点击"批量导入图片"上传；一个证据编号下可包含多张图片，图片层面与上方文字选择可同步。证据独立于测评对象保存，可在证据库中统一管理。
5. 点击"保存测评记录"保存本层面记录。

建议完成一个层面立即保存，避免切换时遗漏。

### 6.4 阶段四 报告编制

本阶段自动汇总现场数据并形成报告内容：

1. **报告数据检查**：系统自动检查系统资产识别、单元测评结果、风险分析表、量化分数计算、总体评价的完成情况，请按提示逐项确认（如提示"1 项待确认"，需处理后再进入导出）。
2. **风险分析表**：按测评单元汇总风险，逐项确认风险等级、风险分析与整改建议；内容来源于风险分析模板库，可按项目实际修改。
3. **系统综合得分**：自动计算并展示综合得分（满分 100）与总体结论（如"基本符合"）。
4. **总体评价与安全问题及改进建议**：核对并完善总体评价分层内容、安全问题及改进建议。

### 6.5 阶段五 报告导出

数据确认无误后，进入报告导出，提供三种成果输出：

| 输出 | 按钮 | 说明 | 预计耗时 |
| --- | --- | --- | --- |
| Word 版报告 | 导出 Word | 按报告模板生成，保留模板原有目录、分页、页眉页脚和表格 | 一般约 30 秒；图片较多或接近 30 MB 时约 1～3 分钟 |
| PDF 版报告 | 导出 PDF | 不可编辑，适用于报送与留档 | 一般约 1 分钟；图片较多时约 2～5 分钟 |
| 原始记录 | 选择位置并生成 | 生成"报告编号+系统名称+原始记录"文件夹，包含原始测评记录、底稿与证据材料，适用于内部留存 | 一般数秒；证据图片较多时需几十秒 |

导出前需完成三级复核：编制人自查、项目负责人审核（重点复核高风险项与评价结论）、技术负责人批准。审核通过后完成正式归档。

注意：Word 报告建议使用 Microsoft Word 打开，页码显示正确；使用 WPS 打开时页码可能相差 1 页，无需修改，导出 PDF 不受影响。

## 七、用户管理（管理员）

用户管理由系统管理员负责，维护账号、状态与密评资质。

### 7.1 添加与编辑用户

1. 点击"＋ 添加用户"。
2. 填写：用户名（英文、数字或下划线，创建后不可修改）、姓名、系统角色（测评人员/项目负责人/审核人员/系统管理员）、密评考试通过时间。
3. 如需登记证书，点击"密评证书"选择图片或 PDF 文件。
4. 点击"确认添加"。系统弹出提示，显示该用户的默认密码，请转告用户并提醒其首次登录时修改。

点击用户行的"管理"按钮可修改姓名、角色、考试时间并重新上传证书；用户名不可修改。

### 7.2 重置密码、启用与禁用

- **重置密码**：点击"重置密码"并确认，系统生成新的默认密码并弹出提示，请及时转告用户。
- **启用/禁用**：点击"启用"或"禁用"切换账号状态；禁用后该账号无法登录，列表状态显示"已禁用"。

用户状态说明：正常（可正常登录）、待改密（首次登录需修改密码）、已禁用（禁止登录）。

### 7.3 批量导入用户

人员较多时可通过 Excel 批量创建账号：

1. 点击"下载导入模板"，获取用户批量导入模板 .xlsx 文件。
2. 在模板中填写用户名、姓名等信息并保存。
3. 点击"批量导入用户"，选择填写好的 .xlsx 文件，等待导入完成。
4. 导入完成后弹出结果窗口，展示所有新增用户的用户名、姓名与初始密码；点击"下载初始密码清单"可将密码表保存为 CSV 文件，妥善保管并分发给各用户。

注意：批量导入的账号首次登录均需修改密码；密评证书需在导入后通过"管理"手动上传。

### 7.4 密评证书管理

用户列表的"密评证书"列展示证书文件名，点击可在新窗口查看；未上传时显示"未上传"。证书文件支持图片与 PDF 格式，通过"管理"按钮上传或更换。

## 八、模板设置（管理员）

模板设置统一维护正式报告模板与原始记录模板，仅管理员可见。页面包含三张模板卡片：

| 模板 | 导入 | 下载 |
| --- | --- | --- |
| 三级报告模板 | 导入 .docx 文件 | 下载当前模板 |
| 二级报告模板 | 导入 .docx 文件 | 下载当前模板 |
| 原始记录模板 | 导入模板文件夹（选择整个文件夹） | 下载模板压缩包 |

使用说明：

- 导出报告时保留模板原有的目录、分页、页眉页脚和表格，系统只替换模板中已有的字段。
- 模板支持自行修改字体、段落、分页、页眉页脚、表格边框等样式；如需新增字段映射，需要通过代码实现。
- 二级、三级报告模板分别对应系统等级为二级、三级的项目，导入后立即生效。

## 九、风险分析模板库（管理员）

风险分析页面按安全层面和测评单元维护"关联威胁、风险等级、风险分析、整改建议"模板，供报告编制阶段自动引用。仅管理员可见。

页面结构：

- **统计区**：显示测评单元总数、已填写分析与建议的数量、待完善数量。
- **层面选项卡**：八个安全层面（物理和环境安全、网络和通信安全、设备和计算安全、应用和数据安全、管理制度、人员管理、建设运行、应急处置），每个层面标注"已配置/单元总数"。
- **模板表格**：展示每个测评单元的威胁、默认风险等级、风险分析、整改建议与完整状态。

主要操作：

1. **编辑模板**：点击行内"编辑"，可修改关联威胁（如 TP1、TN2）、默认风险等级（高/中/低）、风险分析与整改建议；风险分析支持 {系统名称}、{安全层面}、{测评单元} 占位符，生成报告时自动替换。勾选"启用此模板"后保存。
2. **新增模板**：点击"＋ 新增模板"，系统自动定位到尚未配置的测评单元，填写后保存。每个安全层面下的每个测评单元保留一条模板。
3. **导入 Excel**：点击"导入风险模板"选择 .xlsx 文件。Excel 列结构为：安全层面、测评单元、威胁、风险等级、风险分析、整改建议。若 Excel 中存在系统未定义的测评单元，导入会被拒绝并提示具体位置；导入只覆盖 Excel 中填写了的列，空列保留系统原内容。
4. **导出 Excel**：点击"导出 Excel"，可将当前模板库导出为 .xlsx，便于线下批改后再导入。
5. **保存模板库**：点击"保存模板库"统一保存；若存在缺少风险分析或整改建议的单元，系统会提示并定位到该单元。

## 十一、数据备份与恢复

系统数据（项目、测评记录、证据文件）保存在本机数据库中，为防止数据丢失，请定期通过控制台进行备份：

- **备份数据**：在控制台点击"备份数据"，系统在本地生成备份集，并在配置了 NAS 的情况下自动上传 NAS 长期留存。
- **恢复数据**：在控制台点击"恢复数据"，选择本地或 NAS 备份集执行恢复；恢复前系统会先完整下载校验，数据零改动风险。

备份策略、NAS 配置与故障处理的详细操作，请参见《BMPBGS 安装与数据迁移备份恢复指南》。

## 十二、常见问题（FAQ）

**问：忘记密码怎么办？**
答：联系系统管理员，在"用户管理"中点击您账号行的"重置密码"，将生成的新密码告知您，登录后请立即修改。

**问：登录后提示需要修改密码？**
答：首次登录（含管理员重置密码后）必须修改初始密码，按提示设置至少 8 位的新密码即可正常使用。

**问：正在编辑时被退出到登录页？**
答：登录会话有效期为 8 小时，超时需重新登录。请养成完成一个模块就点击保存的习惯，避免未保存内容丢失。

**问：为什么看不到"模板设置""风险分析""测评机构"页面？**
答：这三个页面仅对系统管理员开放，请使用管理员账号登录。

**问：如何开展同一系统的复测？**
答：在项目管理中点击原项目的"复制"，填写新的报告编号与年度后确认。复制会保留现场测评记录与证据图片，可直接在副本上更新。

**问：导出的 Word 报告页码不对？**
答：请使用 Microsoft Word 打开报告；WPS 打开时页码可能相差 1 页，属显示差异，无需修改，导出 PDF 不受影响。

**问：现场照片怎么录入？**
答：在现场测评步骤的记录框中直接 Ctrl+V 粘贴，或点击"批量导入图片"上传；同一证据编号下可包含多张图片。

**问：报告编号必须建档时填写吗？**
答：不必须。建档时可留空，后续在"编辑项目"中补充，或通过"导入 Word"自动带入。

**问：导出的报告很慢或失败？**
答：图片较多时导出需要 1～3 分钟甚至更久，请耐心等待按钮恢复；如失败请检查磁盘空间后重试。

**问：切换深色模式会丢数据吗？**
答：不会。主题切换只改变界面外观，不影响已保存的数据。
